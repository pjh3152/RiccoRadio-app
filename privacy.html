RiccoRadio 개인정보처리방침

시행일: 2026년 11월 19일

RiccoRadio(이하 "앱")는 인터넷 라디오 방송을 듣는 Android 앱입니다. 앱은 회원가입이 없고, 광고나 사용 통계 수집 도구를 포함하지 않습니다. 개발자는 사용자의 개인정보를 수집하거나 서버에 저장하지 않습니다.

1. 기기에 저장되는 정보

정보저장 위치
즐겨찾기, 최근 들은 방송(최대 50개)사용자 기기 안의 앱 저장 공간
설정(테마, 자동 재생, Wi-Fi 전용 재생 등)사용자 기기 안의 앱 저장 공간
진단 로그(재생 상태, 오디오 출력 장치 변화 등 기술 정보)사용자 기본으로 꺼져 있으며, 사용자가 설정에서 켠 경우에만 기기 안의 앱 전용 폴더에 기록합니다. 다시 끄면 기록을 멈추고 파일을 삭제합니다.

이 정보는 개발자나 제3자에게 전송되지 않습니다.

2. 앱이 접속하는 외부 서버

대상목적과 전달되는 정보
Radio Browser (공개 방송국 디렉터리)방송국 목록·국가·장르 조회. 방송을 재생하면 인기 순위 집계를 위해 해당 방송국 ID를 한 번 알립니다. 이름·계정 등 개인 식별 정보는 보내지 않습니다.
각 방송사의 스트리밍 서버사용자가 고른 방송을 재생하기 위해 접속합니다.

인터넷 통신의 특성상 위 서버들은 접속한 기기의 IP 주소를 알 수 있으며, 각 서버의 개인정보 처리는 해당 운영자의 정책을 따릅니다.

3. 권한 사용

권한사용 목적
인터넷, 네트워크 상태방송 목록 조회와 재생, "Wi-Fi에서만 스트리밍" 설정 판단
포그라운드 서비스(미디어 재생), WAKE_LOCK화면이 꺼지거나 다른 앱을 쓰는 동안에도 재생을 이어가기

4. 정보의 삭제

  • 즐겨찾기와 최근 기록은 앱의 설정 → 보관함 관리에서 지울 수 있습니다.
  • 앱을 삭제하면 기기에 저장된 앱 데이터가 모두 삭제됩니다.

5. 아동의 개인정보

앱은 아동을 대상으로 개인정보를 수집하지 않습니다.

Summary (English)

RiccoRadio has no accounts, ads or analytics, and the developer does not collect any personal data. Favorites, recent stations, settings and an optional diagnostic log (off by default) are stored only on the device. The app contacts the public Radio Browser directory to list stations (and reports a station ID once when it starts playing, for popularity counts) and connects to each broadcaster's streaming server to play audio; these servers can see the device's IP address.
